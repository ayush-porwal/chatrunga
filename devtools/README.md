# Dev tools

Local tools for working on the app. Nothing here is bundled into the app or run in CI.

| Tool                    | Run                    | What it's for                                                                                                                                                 |
| ----------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [piece-lab](piece-lab/) | `pnpm devtools:pieces` | Every piece set as the working tree packs it: on a board in both size modes, with each piece's measurements. Reloads when a drawing or the generator changes. |
